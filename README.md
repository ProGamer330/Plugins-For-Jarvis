## 📥 How to Install

Installing is very simple! Just follow these steps.

**Step 1:** Download the repository as a ZIP file from GitHub.

**Step 2:** Extract the downloaded ZIP file.

**Step 3:** Open the extracted folder and find the plugin files you want to use.

**Step 4:** Copy the plugin files.

**Step 5:** Open this folder in your Jarvis MK-50 project:

`Jarvis-MK-50-main\Jarvis-MK-50-main\plugins\`

**Step 6:** Paste the copied files into the `plugins` folder.

That's it! 🎉 You're ready for takeoff! 🚀

## ⚠️ Important

- Make sure you're copying the plugin files into the correct `plugins` folder.
- Keep a backup of your original files before replacing anything.
